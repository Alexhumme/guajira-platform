# Comured — Web

Sitio público construido con Next.js 16, React 19 y Tailwind CSS 4.

## Desarrollo

```bash
npm install
npm run dev        # http://localhost:3000
```

Requiere un `.env` con:

```
NEXT_PUBLIC_API_URL=http://localhost:5000
```

## Build de producción

```bash
npm run build
npm start
```

Documentación general del monorepo en el README de la raíz.
